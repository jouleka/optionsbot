# Security policy

Only the latest commit on `main` is considered for security fixes. This experimental project has not received an independent security audit.

Do not disclose suspected vulnerabilities, credentials, private infrastructure, or exploit details in a public issue. Use GitHub's **Security > Report a vulnerability** form. If private reporting is unavailable, contact the maintainer privately through the channel listed on their GitHub profile.

Include the affected commit and component, impact and preconditions, minimal reproduction steps, and any suggested remediation. Allow reasonable time for triage before public disclosure.

The repository must never contain broker credentials, API tokens, private keys, account identifiers, databases, or identifying production-host information. The supported execution mode is paper-only.
